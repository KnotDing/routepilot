# 提交响应检查

保存成功表示配置已完成数据库事务。后台应用失败会单独报告，已保存内容继续保留，允许重新应用。

| 提交入口 | 返回成功 / 受理的时机 | 后续工作 |
| --- | --- | --- |
| 普通设置、路由后端设置、全局模式 | 校验、合并隐藏凭据、落盘完成 | 后台应用；必要时重建服务 |
| DNS 拦截、Hosts、域名覆盖、BGP 邻居和路由增删改 | 配置事务完成 | 后台热更新或调整路由 |
| 批量删除 | 整批校验并完成一个配置事务 | 后台应用 |
| 备份恢复 | 合并隐藏凭据并完成配置事务 | 后台应用；监听地址切换后重新连接 |
| 手动 / URL 预览路由导入 | 选中路由落盘完成 | 后台发布路由 |
| URL 自动更新规则设置 / 删除 | 配置事务完成 | 调度器独立下载，下载期间不持有保存锁 |
| 本机远程连接档案 | 配置事务完成 | 后续连接及旧凭据清理独立进行；清理失败单独提示 |
| URL 下载预览、Surge Hosts 导入 | 返回后台任务编号 | 完成下载 / 读取；导入落盘后返回实际结果 |
| 规则测试、路由诊断、缓存清理 | 返回后台任务编号 | 页面显示处理状态，完成后展示实际结果 |
| 检查软件更新 | 返回后台任务编号 | 下载 release 元数据；不占用更新状态锁 |
| 在线安装后台更新 | 安装任务受理 | 原有后台下载、校验、安装流程 |
| FRR 预览 / 导出 | 本地生成结果完成 | 无服务重启 |
| 登录 / 退出 | 认证 / 会话操作实际完成 | 登录凭据另行保存并确认 |
| App 偏好 | 本机存储确认 / 浏览器本地保存完成 | 通知授权、软件检查在保存后执行 |

## 后台应用

- 单个工作线程串行调整运行配置；保存锁与运行切换锁独立。
- 连续提交保留最新完整配置；已在处理的版本完成后继续应用最新保存版本。
- 全局页面显示“已保存，后台正在应用”或失败原因，并提供重试按钮。
- DNS / BGP 安全等待保留，但不阻塞保存响应。
- 额外加密记录最后成功运行的配置；重启启用失败时尝试恢复运行配置，保留已保存的新配置及失败提示。
- 诊断等耗时任务的“已受理”与“已完成”分别显示；不能在任务受理时宣称操作成功。
- 并发保存短暂冲突会快速返回明确错误，不等待后台重启。

## 兼容性

配置 API 使用原有响应格式；新的后台实现将落盘与运行应用分开。耗时操作由新页面通过 `Prefer: respond-async` 请求任务接口，旧调用方仍可使用同步结果。远程完整支持需同时升级 App、本机中转后台及远程后台。

本文件是入口与实现审查记录。实际响应仍受网络和数据库存储延迟影响；不承诺远程链路的固定毫秒耗时。
