# Web 远程后端管理

## 使用

打开本地 RoutePilot 管理页，在右上角选择“本地服务 · 切换”，添加连接名称及后端地址，
例如 `http://192.168.20.10:1055` 或 `https://192.168.20.10:1055`。地址支持 IPv4、IPv6 和 localhost；HTTP/HTTPS 均可，地址不能包含用户名、密码、路径、查询参数或片段。
最多保存 32 个连接，连接名称和地址保存在本地 Controller 的 SQLite 中。

选中连接后，使用该远程 Controller 的管理账号登录。页面顶端显示当前后端名称和地址；
所有状态、规则测试、DNS 记录、缓存、配置修改与 FRR 导出都作用于该后端。
远程状态每 3 秒刷新；本地服务保留事件流更新。可随时回到本地，包括连接失败或尚未登录时。
切换会取消旧请求并重建页面，避免跨后端显示旧数据或保留配置草稿。

本地管理认证开启时，需先登录本地服务，才能保存连接及建立远程管理会话。
本地会话失效后返回本地登录；远程退出只清除远程登录，不会退出本地。
密码不会保存到连接配置或浏览器存储，远程 Cookie 和 CSRF 仅由本地服务保存在内存。
服务重启、浏览器本地会话失效或连接闲置超过 30 分钟后，可能需要重新登录远程后端。
本机后台始终尝试在 `http://127.0.0.1:1055` 保留恢复入口；它只接受本机回环连接。状态栏 APP 在后台连接失败时会尝试此入口，且可在未登录时更新已安装的网络后台服务。

## 远程服务准备

在远程 Controller 上配置：

1. “设置 → 通用”：管理监听地址使用具体 IP 和端口，不能使用 `0.0.0.0` 或 `::`。
2. “设置 → 安全”：开启认证并配置用户名和至少 12 字节的密码。TLS 证书与私钥可选；若启用 HTTPS，需在远程主机配置两者。
3. 允许的管理网段包含运行本地 Controller 的出口 IP；防火墙允许该 IP 访问管理端口。
4. 使用 HTTPS 时，证书须受本地 Controller 所在系统信任，并包含管理 IP 的证书名称。程序不跳过证书校验。

非回环监听必须开启认证。HTTPS 是推荐选项；若选择 HTTP，账号、Cookie 和管理流量不会加密，应仅在可信的受保护网络或 VPN 内使用。
远程连接由本地 Controller 发起，需验证它到远程地址的可达性。
管理页所在浏览器无需直接跨域访问远程服务。
App 提供本地网络访问的中英文用途说明；macOS 在需要授权的实际网络访问时管理权限。
`management client network is not allowed` 表示目标后台的管理网段白名单拒绝了请求，
应在目标后台“设置 → 安全 → 允许的管理网段”中加入发起连接的 Controller 出口 IP 或网段。
它与系统的本地网络权限分别管理。

远程修改管理监听地址或 TLS 配置后，编辑已保存连接的地址并重新连接。
macOS 状态栏仍监控本地网络后台；Web 切换远程后端不会切换本地 DNS/BGP 服务。

## 远程异常通知

“设置 → 通知”中的异常筛选、恢复提醒、冷却时间和 Webhook 都作用于当前选中的后端。异常可逐项或按组勾选，系统通知和 Webhook 共用同一份选择；取消全部时不发送异常或恢复通知。BGP 邻居选项适用于当前后端所有已启用的邻居，管理连接中断只能由连接该后端的 App 或浏览器提醒。
Webhook 由远程后台自身发送，不依赖本地管理页面保持打开；接收方需要支持 JSON POST，
字段为 `title`、`body`、`state`、`components`、`at`；通知标题不包含后台名称。
Webhook URL 在 SQLite 中加密保存，设置接口只返回是否已配置，导出备份不含地址。
编辑时留空保留原地址，也可勾选删除；迁移到未配置推送的新后台后需要重新填写地址。

启用本机系统通知并允许 macOS 通知权限后，App 接收当前远程后端的异常和恢复事件。
关闭管理窗口后，App 继续通过同源中继监控当前远程连接，包括连续三次管理请求失败的失联告警。
只使用浏览器时，系统通知需要保持页面打开。
切换后端后监控新连接；退出 App 或远程/本地登录会话失效后停止远程系统通知，需重新登录。
系统通知的偏好属于本机 App 或当前浏览器；后台推送偏好属于各个 Controller。

## 请求隔离

同源管理中继只访问已配置的后端源地址和允许的 Controller API，不支持访问任意 URL、
远程管理中继递归、事件流或任意网页。中继拒绝 HTTP 重定向，使用 HTTPS 时执行标准 TLS 验证，
限制请求／响应大小及连接数量。每个本地浏览器会话、每个后端分别持有远程 Cookie jar。
本地 Cookie、CSRF、Authorization、Origin 不转发；远程 Set-Cookie 不发送给浏览器。
所有本地管理修改仍受本地认证、网段白名单、Origin 和 CSRF 检查。

远程连接元数据在 `/api/v1/management/backends` 管理；中继路径为
`/api/v1/management/relay/{backend_id}/{controller_api_path}`。
导出备份只含连接名称和 URL，不含远程密码或会话。

## 验证范围

自动测试覆盖会话隔离、CSRF、配置目标隔离、连接持久化、删除后不可访问、
重定向拒绝、受限路径及配置编辑不重启本地 DNS。
浏览器验收使用三个独立本机 Controller 实例，包含远程认证及断线恢复。
实际远程主机的证书、允许网段与防火墙仍取决于部署配置；未替用户配置外部设备。

管理控制台的当前后端名称、地址、切换入口与退出位于侧栏底部；手机端在导航菜单中。页面顶部不再重复显示连接横幅。页面语言在“设置 → 通用”修改。

## 远程完整应用在线升级

登录远程后端后，页面自动向该后端检查项目最新正式 Release。检测到新版本时可点击“升级远程应用”，页面内弹出升级窗口，提供“跳过该版本”“稍后升级”“立即升级”和默认折叠的更新说明。确认后由远端下载完整 App ZIP 包，校验 SHA-256、代码签名、App 身份及内置服务版本，同时更新 `/Applications/RoutePilot.app` 和网络服务。远端尚未安装 App 时会安装完整 App，但不会以 root 启动图形界面；已打开的远端 App 会先收到通知：管理窗口可见或 App 处于前台时，由远端用户确认是否重启；仅后台运行时自动重启。选择稍后可继续使用当前窗口，手动重新打开后加载新版本。下载与安装在远端运行，关闭客户端不会终止升级。

v0.5.5 起使用完整应用升级。当前发布只提供完整 App 的 DMG、ZIP 和 SHA256SUMS；即使后台已是当前版本，检测到旧 App 或未安装 App 时仍会提供完整升级。首次需要在远端手动安装一个支持此接口的版本；旧版本没有升级接口，无法直接从页面完成首次升级。目前支持标准路径安装的 macOS Apple Silicon launchd 系统服务，要求 root 所有的程序、配置和安装目录，并启用管理认证。开发进程、自定义服务路径及缺少相应发布包的平台会显示原因。
DMG/ZIP 手动替换 `/Applications/RoutePilot.app` 只更新图形 App，不会替换已安装的本机 launchd 网络后台；已有安装应使用 App 的“设置 → 软件更新”完整升级。手动替换后 App 启动检测到 App 与后台版本不一致时，会提示用 App 携带的后台覆盖正在运行的本机网络后台（需要更新助手或一次管理员授权）。设置中的“自动检查 Beta 版本”默认关闭，启用后会比较正式版与最新 Beta，并由既有提示、自动安装和计划时间设置处理 Beta。若已手动安装 Beta 导致本机版本不一致，也可启用“自动检查 Beta 版本”后在“设置 → 软件更新”中安装同一 Beta 修复后台版本。

升级使用独立的一次性 launchd 助手，保留 SQLite、密钥、配置和服务 plist。DNS 与 BGP 会短暂中断，页面持续轮询进度并尝试重连。现有已认证管理会话通过 root 私有的临时文件交接，不保存密码、不延长会话有效期；交接文件只在 5 分钟内有效，读取后删除。会话已过期或认证设置发生变化时仍需重新登录。

新后台未在 60 秒内启动管理监听器时，助手尝试恢复旧 App 和服务执行文件并重启；失败原因保存在后台升级状态中。回滚针对 App 和服务执行文件，不会撤销新版可能执行过的数据库迁移。本机 App 需要单独更新，远程操作更新当前选中远端的完整安装，不更新发起操作的本机 App。

接口：`GET /api/v1/updates/check`、`GET /api/v1/updates/status`、`POST /api/v1/updates/install`（请求体 `{"version":"vX.Y.Z"}`）。安装接口仅接受最近检查出的正式稳定版本，且 App 或后台至少一个需要更新，不允许降级，不接受任意下载地址、程序上传或执行命令。发布仓库及其 HTTPS 下载来源是升级信任源；SHA-256 和当前临时代码签名校验不等同于开发者身份签名。

## App 保存远程登录凭证

远程登录成功后，App 按菜单栏选择的“本地文件”或“macOS 钥匙串”保存。凭证按连接 ID 与规范化的 HTTP(S) 管理地址分别保存，不覆盖本地后台凭证。再次访问、App 重启或会话过期时，App 在当前浏览器会话内自动向选定远端登录，只把登录结果返回页面，不把已保存的密码返回页面或写入 localStorage。

本机后台会校验登录请求期望的远端地址，防止配置在请求期间变更后把旧密码发送到新地址。自动登录需更新本机后台以支持该校验。密码失效时清除当前存储中的对应凭证并提示重新登录，网络错误或限流不会清除密码；主动退出抑制当前页面的自动登录，重新访问可继续使用保存的凭证。

移除连接或更改管理地址时，App 删除当前存储中的旧凭证。切换存储方式不读取或迁移另一份存储，需登录一次重新保存。旧版未保存远程凭证，因此更新后每个连接需先成功登录一次。本地文件为当前用户可读取的明文，目录权限 0700、文件权限 0600；普通浏览器不使用 App 凭证存储。
