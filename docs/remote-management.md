# Web 远程后端管理

## 使用

打开本地 RoutePilot 管理页，在右上角选择“本地服务 · 切换”，添加连接名称及后端地址，
例如 `http://192.168.20.10:1055` 或 `https://192.168.20.10:1055`。地址支持 IPv4、IPv6 和 localhost；HTTP/HTTPS 均可，地址不能包含用户名、密码、路径、查询参数或片段。
最多保存 32 个连接，连接名称和地址保存在本地 Controller 的 SQLite 中。

选中连接后，使用该远程 Controller 的管理账号登录。页面顶端显示当前后端名称和地址；
所有状态、规则测试、DNS 记录、缓存、配置修改与 FRR 导出都作用于该后端。
远程状态每 3 秒刷新；本地服务保留事件流更新。可随时回到本地，包括连接失败或尚未登录时。
切换会取消旧请求并重建页面，避免跨后端显示旧数据或保留配置草稿。

本地管理认证开启时，需先登录本地服务，才能保存连接及建立远程管理会话。
本地会话失效后返回本地登录；远程退出只清除远程登录，不会退出本地。
密码不会保存到连接配置或浏览器存储，远程 Cookie 和 CSRF 仅由本地服务保存在内存。
服务重启、浏览器本地会话失效或连接闲置超过 30 分钟后，可能需要重新登录远程后端。
本机后台始终尝试在 `http://127.0.0.1:1055` 保留恢复入口；它只接受本机回环连接。状态栏 APP 在后台连接失败时会尝试此入口，且可在未登录时更新已安装的网络后台服务。

## 远程服务准备

在远程 Controller 上配置：

1. “设置 → 通用”：管理监听地址使用具体 IP 和端口，不能使用 `0.0.0.0` 或 `::`。
2. “设置 → 安全”：开启认证并配置用户名和至少 12 字节的密码。TLS 证书与私钥可选；若启用 HTTPS，需在远程主机配置两者。
3. 允许的管理网段包含运行本地 Controller 的出口 IP；防火墙允许该 IP 访问管理端口。
4. 使用 HTTPS 时，证书须受本地 Controller 所在系统信任，并包含管理 IP 的证书名称。程序不跳过证书校验。

非回环监听必须开启认证。HTTPS 是推荐选项；若选择 HTTP，账号、Cookie 和管理流量不会加密，应仅在可信的受保护网络或 VPN 内使用。
远程连接由本地 Controller 发起，需验证它到远程地址的可达性。
管理页所在浏览器无需直接跨域访问远程服务。
App 提供本地网络访问的中英文用途说明；macOS 在需要授权的实际网络访问时管理权限。
`management client network is not allowed` 表示目标后台的管理网段白名单拒绝了请求，
应在目标后台“设置 → 安全 → 允许的管理网段”中加入发起连接的 Controller 出口 IP 或网段。
它与系统的本地网络权限分别管理。

远程修改管理监听地址或 TLS 配置后，编辑已保存连接的地址并重新连接。
macOS 状态栏仍监控本地网络后台；Web 切换远程后端不会切换本地 DNS/BGP 服务。

## 远程异常通知

“设置 → 通知”中的组件筛选、恢复提醒、冷却时间和 Webhook 都作用于当前选中的后端。
Webhook 由远程后台自身发送，不依赖本地管理页面保持打开；接收方需要支持 JSON POST，
字段为 `title`、`body`、`backend`、`state`、`components`、`at`。
Webhook URL 在 SQLite 中加密保存，设置接口只返回是否已配置，导出备份不含地址。
编辑时留空保留原地址，也可勾选删除；迁移到未配置推送的新后台后需要重新填写地址。

启用本机系统通知并允许 macOS 通知权限后，App 接收当前远程后端的异常和恢复事件。
关闭管理窗口后，App 继续通过同源中继监控当前远程连接，包括连续三次管理请求失败的失联告警。
只使用浏览器时，系统通知需要保持页面打开。
切换后端后监控新连接；退出 App 或远程/本地登录会话失效后停止远程系统通知，需重新登录。
系统通知的偏好属于本机 App 或当前浏览器；后台推送偏好属于各个 Controller。

## 请求隔离

同源管理中继只访问已配置的后端源地址和允许的 Controller API，不支持访问任意 URL、
远程管理中继递归、事件流或任意网页。中继拒绝 HTTP 重定向，使用 HTTPS 时执行标准 TLS 验证，
限制请求／响应大小及连接数量。每个本地浏览器会话、每个后端分别持有远程 Cookie jar。
本地 Cookie、CSRF、Authorization、Origin 不转发；远程 Set-Cookie 不发送给浏览器。
所有本地管理修改仍受本地认证、网段白名单、Origin 和 CSRF 检查。

远程连接元数据在 `/api/v1/management/backends` 管理；中继路径为
`/api/v1/management/relay/{backend_id}/{controller_api_path}`。
导出备份只含连接名称和 URL，不含远程密码或会话。

## 验证范围

自动测试覆盖会话隔离、CSRF、配置目标隔离、连接持久化、删除后不可访问、
重定向拒绝、受限路径及配置编辑不重启本地 DNS。
浏览器验收使用三个独立本机 Controller 实例，包含远程认证及断线恢复。
实际远程主机的证书、允许网段与防火墙仍取决于部署配置；未替用户配置外部设备。
