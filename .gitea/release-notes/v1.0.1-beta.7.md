## 软件更新更清晰，自动升级更可靠

- 设置中的“软件更新”和“软件更新设置”合并为一个区域，手动检查与自动更新选项集中管理、统一保存。
- “立即检查更新”跟随当前连接：本机连接检查并升级本机完整应用，远程连接检查并升级远端完整应用。“发现新版本时提示”仅在 App 连接本机后端时显示。
- 更新助手的启用与停用移至状态栏菜单，远程管理页面不再混入操作本机 App 的更新按钮。
- 保存自动更新设置不再重启 DNS 和路由服务；关闭自动检查时会同时关闭自动安装。
- 修复切换正式版与 Beta 检查渠道后复用旧结果的问题，安装时核对检查渠道。
- “跳过该版本”保存在对应后端，App、浏览器和自动安装共同遵守；可取消跳过或手动立即升级。
- 自动更新失败会显示原因并延迟重试；安装调度记录持久保存，重启或升级回滚后仍限制每天最多启动一次自动安装任务。
- 修复下载状态等后台事件覆盖尚未保存的应用偏好、状态栏与 CLI / skill 设置的问题。

这是测试版本，欢迎反馈本机和远程升级体验。
