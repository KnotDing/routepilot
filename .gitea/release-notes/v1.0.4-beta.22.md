# RoutePilot v1.0.4-beta.22

- 新增「决策缓存」和「响应缓存」总开关，可分别按决策与上游设置，操作方式与乐观缓存一致。关闭某类缓存或分项时，同步关闭并禁用对应乐观缓存，保存应用后停止该项缓存的读写与恢复。
- 请求域名排行改为独立持久累计，无组合筛选时不再受 4096 种组合明细上限影响，后出现的高频域名也能进入排行。实时、按来源及历史范围均提供前一百名与精确的其余域名数量。
- 域名卡片显示独立采集起点；升级前丢失的域名明细不倒填。组合筛选继续按真实已保留明细匹配，并显示覆盖请求数，避免将不完整结果误认为全部请求。
- 修复后台重启后已打开的 App 管理页面无法恢复本机会话的问题：使用已保存凭证重新登录并更新 CSRF，短暂连接失败自动重试；主动退出后保持退出，未保存或凭证失效时仍需登录。
- 隐藏 / 固定侧边栏按钮移至左下角，与收起 / 展开按钮并排；仅图标模式同步适配。
