## GitHub 更新检查凭证

- App 的“设置 → 软件更新”现在可以设置 GitHub Access token。凭证保存在本机 macOS 钥匙串，只用于 App 请求 GitHub Releases API。

## GitHub update credentials

- The app's Software Updates settings now support a GitHub access token. It is stored in this Mac's Keychain and used only for GitHub Releases API requests.

这是测试版本。完整 App 安装包包含管理页面、后台与 CLI。

This is a beta release. The full app package includes the management UI, backend, and CLI.
