# RoutePilot v1.0.4-beta.29

- 透明 DNS 使用的 PF 锚点被意外清空后，后台会在健康检查中自动恢复规则并更新租约记录。
- 如果锚点仍有规则但内容与租约不符，后台不会覆盖其他 PF 规则；透明 DNS 会显示异常并记录冲突原因。

When the PF anchor used by transparent DNS is unexpectedly cleared, the backend restores its rules during health checks and updates its lease record.

If the anchor still contains rules that do not match the lease, the backend leaves them untouched, marks transparent DNS unhealthy, and records the ownership conflict.

已有安装请通过“设置 → 软件更新”完成 App 和网络后台的完整升级。自动恢复仅针对 RoutePilot 锚点为空的情况；不会清理全局 PF 规则或 Surge 锚点。
