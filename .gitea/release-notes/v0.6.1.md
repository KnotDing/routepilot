## 浏览器也能升级完整应用

- 从浏览器直接访问管理页面时，可检查并升级当前连接后台所在 Mac 的完整 RoutePilot App。
- 更新说明正常渲染 Markdown，并提供跳过、稍后和立即升级选项。
- 升级保留配置与数据库；远端 App 正在使用时仍需在该 Mac 确认重启，仅后台运行时通知后自动重启。

## CLI 与 AI agent skill

- 完整 App 内置 `routepilot` CLI，支持状态、健康检查、配置、DNS、缓存、路由、BGP、远程连接与软件升级等操作，默认输出 JSON。
- 登录支持从标准输入或私有文件读取密码；会话按后台地址隔离保存，修改操作复用管理认证与 CSRF 校验。
- 内置 `routepilot-control` skill，提供命令参考、操作步骤与异步任务处理说明，方便 AI agent 控制 RoutePilot。
- CLI 操作说明见仓库的 `docs/cli.md`。

## 在设置中管理集成

- 设置新增“CLI 与 skill”：CLI 默认关闭，可启用或禁用；启用后安装本机 `~/.local/bin/routepilot` 入口。
- 禁用后移除 App 管理的入口，直接运行 App 内的 CLI 也会拒绝控制请求，帮助与版本查询仍可使用。
- 支持自动安装 skill 到 Codex、Claude Code 或两者，并随完整 App 更新同步。
- 同名文件或目录冲突时，每项可选择“覆盖”或“跳过”，默认覆盖；覆盖前自动备份，取消对应集成时恢复原内容。
- 集成设置作用于运行管理窗口的本机 App；普通浏览器页面不会修改浏览器所在设备的 CLI 或 skill。
