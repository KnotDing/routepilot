## skill 支持多个 agent

- “设置 → CLI 与 skill”中的安装目标改为复选框，可同时选择 Codex、Claude Code 和 Hermes。
- Hermes 使用 `HERMES_HOME/skills`，未设置时安装到 `~/.hermes/skills`。
- 旧配置中 Codex、Claude Code 或两者的选择自动迁移为对应勾选项。开启自动安装时至少需要选择一个 agent。
- 取消某个目标并保存，会移除对应的 App 管理集成并恢复覆盖前的内容。冲突仍可逐项选择覆盖或跳过，默认覆盖并备份。
- README 的一键安装脚本新增 Hermes 支持，可重复传入 `--agent` 安装到多个 agent。

## 修复远程升级时 App 无法退出

- 后台切换到新版本、App 等待重启时，不再弹出阻塞式的版本不一致提示，避免将后台 App 激活并干扰重启判断。
- 普通版本提示允许 App 正常退出，修复退出请求被 AppKit 的响应链校验取消的问题。
- 保留重启前通知、App 正在使用时需远端确认、仅后台运行时自动重启的行为。
- 已经打开阻塞式版本提示的旧 App，首次升级时可能仍需关闭提示并手动重新打开一次；新进程加载本次修复。

## 清理旧升级流程

- 删除未使用的仅后台更新脚本及其打包、安装暂存要求。
- 删除页面中先升级后台、再升级 App 的兼容分支与旧文案，统一使用完整应用升级流程。
- 删除冗余的升级类型字段、旧更新助手能力标志，以及不等待保存确认的旧 App 页面桥接回退。
- 同步安装包资源清单、既有检查及 AI skill 命令说明。完整应用更新继续校验版本、签名与校验和，并保留服务就绪检查和失败回滚。
