# RoutePilot v1.0.5-beta.6

- 路由发布新增 API 模式：通过路由器管理接口发布与撤销路由，面向不支持 BGP 的网关，不启动 BGP。
- 内置 OpenWrt 预设（ubus JSON-RPC 登录后经 uci 写入 `rp_` 前缀命名路由段并 `network reload` 生效）与 UniFi OS 预设（Integration API + API 密钥，`routepilot-` 前缀路由的创建 / 列出 / 删除），也可用自定义请求模板适配其他设备。
- 自定义模板支持方法、路径、请求头与请求体的变量替换，内置网段、下一跳、路由标识等变量；列表请求必需，每轮先读取路由器现状再对账，重启后不重复创建并自动清理残留路由。
- Hybrid 模式下 Fake-IP 与 DNS 拦截可分别选择 BGP / Static / API；API 配置变更只热替换 API 后端，不重建 BGP 会话、不重启 DNS。
- 路由器地址限制为 HTTP(S) URL；凭据（密码、密钥）加密存储，管理页面留空保留、可显式清除，导出备份不含凭据；自签证书网关可关闭证书校验（明文记录该选择）。
- `api-published` 发布状态与 BGP `announced` 同为控制面边界，不代表转发平面已安装路由；Fake-IP 发放门禁要求所选路由已发布且最近一次对账无错误。

## English

Routing adds an API mode that publishes and withdraws routes through the router's management API for gateways without BGP support. OpenWrt (ubus JSON-RPC sessions with uci-managed `rp_` route sections and `network reload`) and UniFi OS (Integration API with an API key for `routepilot-` routes) presets are included, and custom request templates adapt other devices with variable substitution across method, path, headers and body. Reconciliation reads the router state first each cycle, so routes are not recreated after restarts and leftovers are cleaned up. Hybrid mode can hand Fake-IP and DNS interception to BGP, Static or API separately; API configuration changes hot-swap only the API backend without rebuilding BGP sessions or restarting DNS. Router credentials are stored encrypted and excluded from exported backups, router addresses must be plain HTTP(S) URLs, and certificate verification can be disabled for self-signed LAN gateways. `api-published` marks a control-plane boundary like BGP `announced` and does not prove forwarding-plane installation; the Fake-IP gate requires the chosen routes published with the latest reconciliation free of errors.
