## 通知异常逐项选择

- “设置 → 通知”新增 13 项异常选择，覆盖 Surge CLI / HTTP API / Fake-IP DNS、BGP 引擎 / 邻居 / Fake-IP 路由、真实 DNS / DNS 监听器 / 透明 DNS / DNS 拦截路由、控制器 / 数据库 / 管理连接。
- 支持逐项勾选、按组选择、全选和取消全部，选择随后台配置持久保存。
- App 系统通知、浏览器通知和后台 Webhook 共用筛选；恢复提醒只针对已选择的异常。取消全部后不发送异常或恢复通知。
- 旧配置保留原有通知范围；Webhook 每次发送或重试前重新筛选当前选择。

## 远程后台在线升级

- 登录支持升级的远程后台时自动检查项目最新正式 Release，发现更高版本后可确认“升级远程后台”。
- 远端下载后台安装包，校验 SHA-256、代码签名、版本及平台，再通过独立的一次性 launchd 助手替换程序并重启。
- 展示下载、校验、重启和完成状态，页面尝试自动重连；关闭客户端不终止远端任务。
- 配置、SQLite、密钥和服务配置保留。新后台未就绪时尝试恢复旧执行文件并重启；执行文件回滚不会撤销新版数据库迁移。
- 已认证管理会话通过 root 私有临时文件交接，不保存密码、不延长会话期限，读取后删除；退出登录或修改认证会使交接失效。
- 升级接口需要管理认证与 CSRF 校验，只允许最近检查出的更高稳定版本；不接受任意下载地址、程序上传或执行命令。
- 发布的后台包增加临时代码签名；下载信任源是项目仓库及其 HTTPS 来源，校验不等同于开发者身份签名。

## 安装与更新

Apple Silicon Mac 请下载 **RoutePilot-macos-arm64.dmg**，独立后台请下载 **surge-controller-macos-arm64.tar.gz**。

**已有旧后台需在远端手动更新至本版一次，才能获得在线升级接口。** 当前支持标准路径安装、root 所有的 macOS Apple Silicon launchd 系统服务；此后可从客户端更新该远程后台，通常无需再次输入远端管理员密码。升级会短暂中断 DNS 与 BGP。

更新本机 App 后，已安装的网络后台仍需通过菜单栏“更新网络后台服务”更新。本机 App 的安装流程仍需管理员授权，本版的免重复授权路径适用于远程后台在线升级。

前端、Go 后台及原生 App 编译通过，发布脚本语法检查通过；尚未执行实际远程升级、回滚和通知推送的运行验收。下载文件可使用 **SHA256SUMS** 校验。
