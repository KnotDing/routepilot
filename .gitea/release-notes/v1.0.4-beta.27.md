# RoutePilot v1.0.4-beta.27

- 支持同时打开多个管理窗口，分别控制本地和不同远程后端。从状态栏「打开管理窗口」选择后端即可；已有相同目标的窗口直接唤起并从最小化恢复，保留未保存的编辑。
- 窗口标题显示后端名称和地址；每个窗口独立保存连接、登录会话和页面状态。窗口内切换后端只影响当前页面，关闭或最小化一个窗口不影响其他窗口。
- 登录及保存结果返回各自来源窗口，避免后台页面的回调落到其他页面。已保存凭证可供新窗口独立登录；未保存凭证时需在新窗口登录。本机 App 偏好保持共享。
- 多个远程窗口分别维护系统通知监控，关闭或最小化后由 App 接续检查；本地管理地址变更或恢复后，各窗口保留各自后端选择。
- 为远程读取、写入和后台任务轮询绑定所选后端地址。连接地址被其他窗口修改时，旧页面提示重新连接，阻止请求转向新目标。

已有安装请通过“设置 → 软件更新”完成 App 和网络后台的完整升级，使多窗口与地址绑定保护一起生效。普通浏览器标签页仍遵守浏览器自身的同站点 Cookie 共享规则。
