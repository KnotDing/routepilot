# RoutePilot v1.0.5-beta.7

- Hybrid 模式下手动路由新增独立的「手动路由方式」选择，可在 BGP / Static / API 之间切换，与 Fake-IP 和 DNS 拦截的选择互不影响。
- 旧配置未保存过该选择时默认保持 BGP，行为与升级前一致；选择 API 时通过路由器管理 API 发布并撤销，选择 Static 时转为外部声明，RoutePilot 不安装也不验证。
- 手动路由改选 API 只热替换路由器 API 后端，不重建 BGP 会话、不重启 DNS；仅当 BGP 只服务手动路由且全部改出时才关闭 BGP 模块。
- 修正两处状态统计：手动路由不再继承 Fake-IP 的静态确认标记，也不再计入 DNS 拦截就绪的分母（此前 API 模式下未发布的手动路由会错误压低 DNS 拦截就绪状态）。
- 状态栏路由详情显示手动路由后端，管理页路由表按行显示手动路由的实际分发方式。

## English

Hybrid mode gains an independent "manual route method" selection so manual routes can be distributed through BGP, Static or the router API, separately from Fake-IP and DNS interception. Configurations saved without the selection keep manual routes on BGP, matching earlier behaviour. Choosing the API publishes and withdraws manual routes through the router management API; choosing Static turns them into external declarations that RoutePilot neither installs nor verifies. Moving manual routes to the API only hot-swaps the router API backend without rebuilding BGP sessions or restarting DNS; the BGP module shuts down only when no other path still needs it. Two status accounting fixes ship alongside: manual routes no longer inherit the Fake-IP static confirmation flag and no longer count toward the DNS interception readiness denominator, which previously let unpublished manual routes wrongly drag DNS interception readiness down in API mode. The status bar routing details now show the manual route backend and the routing table lists each manual route's actual distribution method.
