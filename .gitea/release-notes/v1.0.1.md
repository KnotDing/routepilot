## ✨ v1.0.1：软件更新更清晰，自动升级更可靠

本次正式版汇总 v1.0.0 之后 Beta.1–Beta.7 的改进，并加入远程连接时的版本提示优化。

### 🔄 一个页面，更新当前连接的 Mac

- “软件更新”与“软件更新设置”合并：手动检查、自动检查、检查间隔、自动安装和每天的安装时间集中管理、统一保存。
- 更新设置保存在当前连接的后端。连接本机时更新本机完整应用，连接远端时更新远端完整应用；App、管理页面与网络服务同步升级。
- “发现新版本时提示”仅在 App 连接本机后端时显示。更新助手的启用与停用移至状态栏菜单。
- 移除重复的在线升级与独立 Beta 检查入口。启用“自动检查 Beta 版本”后，统一的“立即检查更新”和自动检查会比较正式版与编号 Beta；版本号相同时优先正式版。

### 🛠️ 可靠的自动安装与版本修复

- 自动安装按后端所在 Mac 的本地时间执行；当天错过计划时间时，服务启动后会补装。
- 安装调度记录持久保存，重启或升级回滚后仍限制每天最多启动一次自动安装任务。检查或启动任务失败会显示原因，并延迟重试。
- “跳过该版本”保存在对应后端，App、浏览器与自动安装共同遵守；取消跳过或手动立即升级可恢复安装。
- 保存自动更新设置不再重启 DNS 或路由服务；关闭自动检查时同时关闭自动安装。
- 修复正式版与 Beta 渠道切换时复用旧检查结果的问题，安装前核对检查渠道。
- App 与本机后台版本不一致时，可用 App 自带的后台直接覆盖修复，无需重新下载完整安装包；更新助手已启用时免重复管理员授权。
- 后端计划自动安装不要求启用管理认证；浏览器和远程管理页面发起手动升级仍需管理认证。

### 🧭 提示和偏好更稳妥

- 远程连接时，本地和远端分别使用 Beta 与正式版，会显示中性色版本信息；同渠道版本不一致、版本信息不完整时仍显示更新警告。
- 修复更新下载等后台事件覆盖未保存的应用偏好、状态栏及 CLI / skill 设置的问题。
- 移除已弃用的后台名称：旧配置仍可读取，名称不再出现在设置、状态接口和通知标题中；Webhook JSON 不再包含 `backend` 字段。

### ⬆️ 升级

已有安装请在“设置 → 软件更新”检查并升级，保留配置、数据库和登录凭证。完整升级会短暂重启网络服务；远端 App 正在使用时由远端用户确认重启，仅后台运行时自动重启。

提供 Apple Silicon macOS 的 DMG、完整 App ZIP 与 SHA256SUMS。手动替换 App 后若本机后台仍是旧版，可使用启动时的覆盖修复提示。
