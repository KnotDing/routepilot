# RoutePilot v1.0.4-beta.23

- 新增「强制重启远程 App」：远端升级完成但仍在等待用户确认、选择稍后重启或重启失败时，可在本端确认后关闭并重新打开远端 App，无需远端用户在场。此操作只重启图形 App，网络后台、DNS 和 BGP 继续运行。
- 远程后端已更新、仅 App 尚未重启时，改为普通灰色提示，说明可继续正常管理，不再显示醒目的升级告警。
- 等待远端用户确认或稍后重启时降低状态查询频率；实际重启时继续及时显示进度。重复点击不会启动多次重启，已手动重开的 App 不会被误关。

强制重启可能丢弃远端管理页面尚未保存的内容。该按钮需要远端后端支持本版本的新接口；旧版后端仍可在远端手动重新打开 App。
