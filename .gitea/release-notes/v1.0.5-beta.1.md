# RoutePilot v1.0.5-beta.1

- 修复 RoutePilot 透明 DNS PF 锚点意外清空后无法恢复规则的问题。后台会在健康检查中恢复空锚点；遇到不匹配的现存规则时保留现场并报告冲突。
- 在状态栏“本机后台”菜单中新增“重启后台服务”，可在确认后请求管理员权限重启本机网络后台，并等待服务恢复。

Fix recovery when the PF anchor used by RoutePilot transparent DNS is unexpectedly cleared. The backend restores an empty anchor during health checks and reports conflicts without overwriting existing mismatched rules.

Add a “Restart Backend Service” action to the status bar’s “Local Backend” menu. After confirmation, it requests administrator authorization to restart the local network backend and waits for recovery.

已有安装请通过“设置 → 软件更新”完成 App 和网络后台的完整升级。当前版本的 PF 自动恢复仅针对 RoutePilot 锚点为空的情况；不会清理全局 PF 规则或 Surge 锚点。
