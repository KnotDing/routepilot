# RoutePilot v1.0.4-beta.5

## 更新进度与监控修复

- 检查更新只读取版本和说明，不再提前下载安装包；确认立即安装后由更新助手下载，已有通过校验的缓存仍可复用。
- 管理页面、本机安装窗口和远程更新显示实际下载进度与下载量。服务器未提供总大小或旧助手未提供进度时显示不确定进度，不伪造百分比。
- 修复从没有来源明细的旧版统计升级后，部分环境持续提示「历史统计保存失败：监控维度与完成请求数不一致」的问题。全局计数与旧来源计数完全分离，保存失败不再因新请求误增旧来源而持续发生。
- 来源流向图与来源请求占比表的分母同步排除隐藏的旧来源请求，显示来源的占比合计为 100%；已保存的累计统计保留。
- DNS 处理去向单独展示「响应缓存」和「乐观响应缓存」，按每次请求实际是否使用旧值响应区分；实时、历史、策略去向和指标保持同一口径。

旧版本历史中未记录的缓存命中类型不会回填拆分。下载进度使用实际传输字节；它不代表安装、校验或重启完成。

## Update progress and monitoring fixes

- Check release metadata and notes without pre-downloading packages. Download after installation is confirmed, retaining reuse of verified cache files.
- Show actual downloaded bytes and progress in the management page, local installation window and remote updates. Use indeterminate progress when total size or progress fields are unavailable.
- Fix persistent history-save failures after upgrading source-less statistics: restored global and legacy source counters no longer share mutable maps.
- Exclude hidden pre-collection requests from source-flow and source-share denominators so displayed source shares sum to 100%, while preserving stored cumulative totals.
- Separate regular response-cache and optimistic response-cache destinations using the actual response returned per request, consistently across live statistics, history, policy paths and metrics.

Missing cache distinctions in older history are not reconstructed. Download percentages measure transferred bytes, not installation or restart completion.
