# RoutePilot v1.0.4-beta.7

## 软件更新设置

- 去掉「检查与升级针对当前连接的后端所在 Mac。」提示。
- 「立即检查更新」移到「保存设置」旁边。本机 App、浏览器和远程管理使用一致的按钮位置；检查仍操作当前连接的更新目标，进度和升级确认保持原有行为。

本版包含此前测试版的客户端备注、客户端强制 DIRECT / SURGE / REJECT 策略，以及与 DNS 请求流向并列的「客户端策略流向」。

## Software update settings

- Remove the explanatory text about checking and upgrading the Mac hosting the connected backend.
- Place Check for updates beside Save settings across the local App, browser and remote management. Preserve the connected update target, progress and upgrade confirmation behavior.

Includes client names, forced DIRECT / SURGE / REJECT client policies, and Client policy flows beside DNS request flows from the preceding beta.
