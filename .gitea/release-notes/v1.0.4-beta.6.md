# RoutePilot v1.0.4-beta.6

## 大屏监控

- 新增客户端 → 策略 / 策略组流向图，与 DNS 请求流向并列，沿用相同卡片、配色和流带样式。
- 使用实际逐源策略命中计数，流带、数量与占比保持一致，支持实时、历史和单源筛选，并显示客户端备注名称。来源和策略较多时合并小项，可展开核对数量；手机端上下排列。

## 客户端设置

- 客户端页面新增配置列表，可手工添加 IP 或从已发现客户端选择，支持编辑与删除。
- 支持备注名称，客户端统计与大屏来源显示名称和 IP，匹配与历史统计身份仍使用 IP。
- 可指定自动、DIRECT、SURGE 或 REJECT。强制策略优先于原有域名与 Surge 规则；自动保留备注并恢复正常规则。
- 支持 IPv4 / IPv6，归一 IPv4 映射地址，拒绝重复或无效配置。设置在当前连接后端持久保存，跨重启恢复，支持 DNS 分区备份 / 恢复。
- 强制查询仍保留格式校验、防环路、ANY 拒绝与 Fake-IP 健康门禁；强制 SURGE 不会因服务不可用而绕行真实 DNS。
- 保存沿用异步配置应用状态。旧版后端局部禁用新配置功能；旧版设置表单不会清空客户端设置。

备注最多 80 个字符，每个后端最多 4096 个客户端配置。以后台实际看到的源 IP 匹配，NAT 后共享地址的客户端不会被拆开。

## Client settings

- Add, edit and delete client configurations by IP, including selection from discovered clients.
- Assign remark names shown in client statistics and monitoring source views. IPs remain the matching and historical statistics identity.
- Select Automatic, DIRECT, SURGE or REJECT. Forced policies override normal domain and Surge rules; Automatic retains the name and restores regular policy evaluation.
- Support IPv4 and IPv6, normalize IPv4-mapped addresses, and reject duplicate or invalid entries. Persist settings on the connected backend across restarts and DNS configuration backup/restore.
- Preserve query validation, loop protection, ANY refusal and Fake-IP health gates. Forced SURGE never falls back to real DNS when unavailable.
- Retain asynchronous configuration activation and graceful old-backend behavior. Older settings forms cannot erase separately edited client settings.

Names support up to 80 characters, with up to 4096 configurations per backend. Matching uses the source IP observed by the backend, so clients sharing a NAT address share that identity.
