# RoutePilot v1.0.4-beta.19

- 乐观决策与乐观响应缓存采用分组总开关，启用后显示各项独立开关；关闭某项只控制该项乐观缓存。
- 乐观响应缓存包含 Surge DNS 解析结果，可单独启用或关闭；各决策和上游分别显示缓存条目、命中、核对、不一致及不一致率。
- Surge 缓存保持客户端与查询隔离，继续校验健康、路由状态、Fake-IP 网段及发行 TTL；后台重启保留可靠性统计并重新取得响应。
- 本机通知设置移到 App 状态栏菜单的「应用偏好 → 本机通知设置」，管理页面移除本机通知卡片。
- 通知新增缓存不一致率、突发 DNS 请求量与持续高请求量告警，可分别选择并调整阈值，通知详情显示实际统计数值。
- 减少中文菜单翻译、查询历史记录与无关状态读取的重复计算；侧边栏收起按钮移到退出旁，DNS 拦截确认与新增操作并列。
