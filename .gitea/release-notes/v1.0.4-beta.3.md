# RoutePilot v1.0.4-beta.3

## 来源流向与占比布局

- DNS 请求流向图的「DNS 流入」直接按客户端源 IP 分类，连接到实际 DNS 处理去向，流带使用真实逐源去向计数和统一比例尺。
- 移除独立的「按源统计 DNS 流入」区域，在流向图下方以与策略命中占比一致的比例条表格显示各源请求数与占比；点击来源可查看该源的流向和策略命中，再次点击返回全部来源。
- 实时和历史视图使用相同布局。流向图最多显示前十个源，其余来源保留实际去向并合并展示，占比表仍提供全部保留来源。
- 旧版后端缺少逐源流向时说明原因并保留接入方式图，不推算缺失的流向关系。

来源表以全部流入请求为占比分母，流向图以当前范围内已完成请求为分母；两者明确区分。七天历史保留和统计持久化继续支持。

## Source flows and share layout

- Classify **DNS ingress** directly by client source IP in the flow diagram, linked to observed DNS handling destinations with a common request-count scale.
- Replace the standalone source statistics area with a share table beneath the diagram, using the same proportion bars as policy hits. Click a source to inspect its flows and policy hits; click it again to return to all sources.
- Apply the same layout to live and historical views. Show the ten largest sources in the diagram and aggregate smaller sources by their actual destinations, while retaining all tracked sources in the share table.
- Explain missing source flow details on older backends and retain the ingress-type diagram without inferring missing relationships.

The source table uses all incoming requests as its denominator; flow ribbons use completed requests in the current scope. Persistent statistics and seven-day history remain available.
