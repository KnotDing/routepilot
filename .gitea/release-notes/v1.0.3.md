# RoutePilot v1.0.3

## 远程管理与安全

- CLI 和 agent skill 设置可作用于当前连接的本机或远程后端，并显示目标 Mac、桌面用户和安装路径。
- 可配置管理 IP 免认证白名单、可信反向代理、代理访问地址和客户端 IP 请求头；默认白名单为空，写操作仍受 CSRF 校验。
- 支持按配置分区备份与恢复，未选择的分区和已有凭证会保留。

## 缓存与 BGP

- 决策和 DNS 响应缓存新增可靠性统计，记录旧值命中、已核对与不一致请求，并在缓存重建和服务重启后保留。
- BGP 邻居详情展示会话、地址族统计和双方通告能力；远端通告能力按稳定顺序显示。

## 更新与界面

- 软件更新源可选择 GitHub 或 Gitea，默认使用 GitHub。App 可将 GitHub Access token 保存在本机 macOS 钥匙串；选择 Gitea 时隐藏 token 设置。
- 更新源与 token 使用一致的表单样式；帮助提示气泡紧贴触发按钮。
- 优化管理侧栏图标与 DMG 安装指引。

## Remote management and security

- Configure CLI and agent skills on the currently connected local or remote backend, with the target Mac, desktop user, and install path shown.
- Add management IP allowlists, trusted reverse proxies, proxy origins, and client IP headers. The allowlist is empty by default, and write requests retain CSRF protection.
- Back up and restore selected configuration sections while preserving unselected sections and existing credentials.

## Cache and BGP

- Decision and DNS response caches report stale hits, verified results, and mismatches. Reliability counters persist across cache rebuilds and service restarts.
- BGP peer details show session state, address-family statistics, and both sides' advertised capabilities in a stable order.

## Updates and interface

- Choose GitHub or Gitea as the update source, with GitHub as the default. The app can store a GitHub access token in the local macOS Keychain; the token setting is hidden when Gitea is selected.
- Update source and token use a consistent form style, and help popovers open beside their trigger buttons.
- Refine management sidebar icons and the DMG installation guide.
