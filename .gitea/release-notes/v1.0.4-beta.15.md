# RoutePilot v1.0.4-beta.15

## 中文

- DNS 请求流向与客户端策略流向图支持点击流带：选中的流向高亮显示，其余流带变淡，图下方固定显示该流向的精确请求数与占比；再次点击取消选中，实时刷新时数值保持最新。

## English

- Click any ribbon in the DNS request flow and client policy flow charts to highlight that flow while dimming the rest. The exact request count and share stay pinned below the chart; click again to clear the selection, with values kept current during live refreshes.
