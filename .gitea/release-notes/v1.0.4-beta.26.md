# RoutePilot v1.0.4-beta.26

- 配置按实际依赖的模块应用：修改 DNS、缓存或健康检查设置时，保留未改变的 BGP 邻居会话；修改 BGP 全局参数时，DNS 继续运行。
- 日志与隐私设置支持热更新，包括查询记录开关、域名保留、记录容量和主机名探测，无需重启 DNS 或 BGP。关闭查询记录会清空已有记录，缩小容量保留最新记录。
- 客户端备注与强制查询策略即时应用，新请求使用更新后的策略，无需重建后台运行实例。
- 「日志与隐私」新增默认关闭的「截断探测主机名的域部分」：可将 `device.example.local` 显示为 `device`，客户端列表和大屏同时生效。手工备注不受影响，关闭后立即恢复完整名称，无需重新探测或重启服务。
- BGP 邻居和手动路由按差异更新；DNS 监听启用失败时，恢复与重试保留原 BGP 实例。DNS 暂停期间，未绑定健康状态的手动路由继续保留。
- 仍保留必要的安全联动：DNS 源地址也用于 BGP 邻居绑定时需同步更新 BGP；Fake-IP 门禁、旧响应排空、TTL 等待与健康绑定路由规则继续生效。

测试版面向 Apple Silicon、macOS 13 及以上。已有安装请通过“设置 → 软件更新”完成 App 与网络后台的完整升级。包校验不代表真实网关、PF、LAN / IPv6 或长期运行已验收。
