# RoutePilot v1.0.4-beta.16

## 中文

- 静态 DNS 拦截的网关路由确认移到“DNS 拦截”页：点击“确认网关路由已配置”立即保存，已确认时显示“✓ 网关路由已确认”并置灰，相关配置变更使确认失效后可重新确认，无需返回路由设置。

## English

- Confirm static DNS interception gateway routes directly on the DNS interception page. Click “Confirm gateway routes are configured” to save immediately; confirmed routes show a disabled gray “✓ Gateway routes confirmed” button. Relevant configuration changes reset the declaration so it can be confirmed again, without returning to routing settings.
