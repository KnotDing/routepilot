# RoutePilot v1.0.5-beta.3

- DHCP 设备属性改为直接从租约列表编辑，移除独立的设备配置区域。没有有效租约的已配置设备仍保留在列表中，也可手动添加设备。
- 设备名称、固定地址和九项 DHCP 选项在同一编辑窗口中修改；保存设备属性不会提交尚未保存的全局配置。
- DHCP 输入沿用设置页样式，移除多余分组边框和重复标题，修复保存按钮区紧贴租约卡片的间距问题。
- 调整窄窗口下的租约列表与设备编辑窗口，补充明暗主题检查。

DHCP 默认关闭；真实 iOS 租约获取和自定义路由采纳仍待现场验收。DHCPv4 能力及启用前检查详见 [配置说明](https://github.com/KnotDing/routepilot/blob/main/docs/dhcp.md)。

## English

- Edit DHCP device properties directly from the lease list, including configured devices without an active lease.
- Device changes save independently without submitting unsaved global settings.
- Removes duplicate option headings, fixes spacing above the lease panel and improves the responsive device editor.

DHCP remains disabled by default. Real iOS lease acquisition and custom route adoption remain unverified.
