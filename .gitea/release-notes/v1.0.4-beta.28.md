# RoutePilot v1.0.4-beta.28

- “设置 → Surge”中的“Surge IPv4 下一跳”改为选填。留空时由当前连接的后端自动读取 Surge VM 的 IPv4 地址，手动填写时优先使用指定地址；IPv6 下一跳仍按需填写。
- 设置字段旁显示自动探测地址、等待旧响应到期的状态或失败原因。探测通过 Surge CLI 的 VMNET 状态完成，每 30 秒最多一次；Surge 增强模式未运行或当前 CLI 不支持时，可填写手动地址。
- 自动地址变化或探测失败时暂停发放新的 Fake-IP，按已发放响应的 TTL / 宽限期保留旧路径，再更新或撤回路由；保留 DNS 运行实例和 BGP 邻居会话。静态网关路由仍由用户手动配置，自动地址变化后需要重新确认。
- “Fake-IP 网段”改为单行输入框，多个网段用逗号分隔，同时支持中文逗号。

已有安装请通过“设置 → 软件更新”完成 App 和网络后台的完整升级。自动探测在所连接后端所在的 Mac 执行，不会将管理端本机的地址写到远程后端。
