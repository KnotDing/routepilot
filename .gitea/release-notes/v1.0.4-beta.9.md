# RoutePilot v1.0.4-beta.9

## 客户端列表

- 备注和查询策略直接从「客户端列表」每行编辑，移除单独的客户端设置卡片。可在编辑窗口清除设置，恢复自动策略。
- 已配置但暂无请求记录的客户端仍显示在同一列表，缺失统计显示「—」。
- 客户端请求数、分流决策、错误数、最后活动与淘汰汇总持久保存，配置重新应用和后台重启后继续累计。保存失败显示原因并自动重试。

每五秒保存检查点，正常退出保存最终统计。异常退出可能丢失最近尚未保存的增量；旧版本未保存的客户端计数不会倒填。统计明细继续保留最多 4096 个地址。

## Client list

- Edit names and query policies directly from each client row. Remove the separate settings card and clear settings from the editor to restore automatic policies.
- Keep configured clients without current request records in the same list, with unavailable statistics shown as a dash.
- Persist request, decision, error, last-activity and eviction statistics across configuration activation and backend restarts. Show storage errors and retry automatically.

Checkpoint every five seconds and save final counts on normal shutdown. Abrupt termination may lose unsaved changes. Older unsaved statistics are not reconstructed; detailed statistics retain at most 4096 addresses.
