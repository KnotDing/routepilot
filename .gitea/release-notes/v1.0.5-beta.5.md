# RoutePilot v1.0.5-beta.5

- 统计卡片中的数值在宽度不足时自动缩小字号，保持完整单行显示；窗口变宽后恢复原字号，不截断或缩写数值。
- DNS 概览、缓存、客户端、路由与大屏监控使用同一套适配逻辑，支持数值更新及窗口尺寸变化。
- 保留此前 DHCP 输入样式、租约列表内设备编辑、间距和移除多余分割线的修复。

## English

Metric values shrink to fit their cards on a single line and return to their normal size when space allows. Complete values remain visible without truncation or abbreviation across DNS, cache, client, routing and monitoring cards.
