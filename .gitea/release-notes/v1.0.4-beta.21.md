# RoutePilot v1.0.4-beta.21

- 大屏监控新增「请求域名占比」，沿用来源排行的比例条、数量与占比样式，支持点击域名筛选。
- 页面支持组合筛选请求来源、DNS 处理去向、策略 / 策略组、最终策略、域名和响应码，实时与历史图表使用相同条件。
- 筛选名称显示在选框前方；请求来源与域名排行的行距收紧，同样空间显示更多内容。
- DNS 请求流向与客户端策略流向并列时等高，较矮图通过增加纵向间距对齐，字体与流带粗细保持不变；上下排列时恢复各自高度。
- 域名及组合统计跨重启保留，敏感数据保护同时隐藏域名、策略及筛选值。缺少新维度的旧历史明确提示不可用，不补造关联。
- 历史统计读取失败时保留仍可读取的实时统计。
