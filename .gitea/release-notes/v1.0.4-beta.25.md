# RoutePilot v1.0.4-beta.25

- 「设置 → 日志与隐私」新增默认关闭的「探测主机名」。开启后，由当前后端在后台反向查询未备注客户端的主机名；客户端列表和大屏优先显示手工备注，其次显示探测结果，仍按 IP 统计和筛选。
- 主机名探测带超时、结果缓存和失败重试，不阻塞客户端 DNS 请求；失败时保留 IP 并显示原因。探测结果不会自动写入备注，也不会改变客户端策略。
- App 状态栏的「打开管理窗口」支持展开选择本地服务和已保存的远程后端，悬停显示地址，勾选标示上次选择。只有本地后端时，直接打开本地服务。
- 已打开窗口中选择当前后端仅唤起窗口；切换其他后端重新加载页面并沿用已有登录与远程管理流程，状态栏继续监控本机后台。

主机名能否探测成功取决于后端所在网络是否提供反向解析（PTR）。切换后端会丢弃管理页面尚未保存的编辑。
