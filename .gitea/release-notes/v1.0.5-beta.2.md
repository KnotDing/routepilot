# RoutePilot v1.0.5-beta.2

## 新增 DHCPv4 服务

- 新增独立 DHCP 管理页面，可选择局域网接口、子网、动态地址池及固定地址。
- 支持网关、多个 DNS、Option 121 自定义路由、NTP、网络启动文件或 URL、启动服务器、TFTP、租期和域名；每项均可按设备 MAC 独立继承或覆盖。
- 启用前探测所选接口上的其他 DHCP 服务器，并检查 macOS 网口是否使用静态 IPv4。发现已有服务器、DHCP 地址或检查失败时给出提示，允许取消启用。
- 新增租约列表及持久化恢复、地址冲突隔离、配置备份分区、CLI 和远程管理支持。
- DHCP 配置独立应用，避免因 DHCP 修改重启 DNS 或 BGP。

DHCP 默认关闭。启用前应停用同一子网的其他 DHCP 服务器，并为服务网口配置静态地址。探测无响应不能保证不存在其他服务器；客户端需重新获取租约才会获得新配置。本测试版尚未完成真实 iOS 租约和路由采纳验收。

当前提供本地广播域 DHCPv4；网络启动和 TFTP 字段用于指定已有服务器，不托管启动文件。配置说明见 [DHCP 文档](https://github.com/KnotDing/routepilot/blob/main/docs/dhcp.md)。

## English

- Adds an optional DHCPv4 server with a dedicated page, address pools and per-device reservations.
- Gateway, DNS, classless routes, NTP, network boot, next-server, TFTP, lease duration and domain support independent per-device overrides.
- Preflight checks warn about responding DHCP servers, DHCP-configured interfaces and inconclusive checks before enabling.
- Includes persistent leases, conflict quarantine, configuration backup, CLI and remote management. DHCP changes apply independently of DNS and BGP.

Disabled by default. Renew client leases after configuration changes. Real iOS lease acquisition and route adoption remain unverified in this beta.
