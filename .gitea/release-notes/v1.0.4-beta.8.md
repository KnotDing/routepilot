# RoutePilot v1.0.4-beta.8

## 页面调整

- 软件更新设置去掉无用分割线，保留「保存设置」旁的「立即检查更新」按钮。
- 修复流向图中小请求量客户端及策略名称与占比文字重叠。按两侧节点数量增加图表高度与节点间距，流带和节点宽度仍按真实请求数同比例绘制。

包含此前测试版的客户端备注、强制 DIRECT / SURGE / REJECT、实时与历史统计，以及并列的「DNS 请求流向」和「客户端策略流向」。

## Interface adjustments

- Remove the unused divider in software update settings. Keep Check for updates beside Save settings.
- Prevent client and policy labels from overlapping for small request shares. Increase chart height and spacing according to both node lists while preserving proportional node and flow-band sizes.

Includes client names, forced DIRECT / SURGE / REJECT policies, live and historical monitoring, and the paired DNS request flows and Client policy flows charts.
