# RoutePilot v1.0.4-beta.11

## 监控与导航

- 两张流向图默认只显示客户端备注名称，点击可切换为 IP，再点击切回；无备注显示 IP，长名称完整换行。
- 客户端策略流向增加「命中策略 / 策略组 → 最终策略」，按真实请求路径绘制，支持实时、历史和单源筛选。宽度不足时放到 DNS 请求流向下方。
- 「请求来源占比」改为与策略命中相同风格的排行比例条，移除表格并保留点击来源筛选。
- 侧边栏支持完整显示、仅图标和完全隐藏。隐藏后鼠标移到左侧边缘悬浮展开，也可固定回来；状态在当前管理界面保留。

包含此前测试版的客户端列表行编辑、统计持久化，以及底部并排的检查 / 安装更新按钮。

## Monitoring and navigation

- Show client names alone in both flow charts, with click-to-toggle IP addresses. Unnamed clients show IPs; long labels wrap in full.
- Add matched-policy/policy-group to final-policy flows using observed request paths for live, historical and source-filtered data. Stack below DNS flows when space is limited.
- Replace the request source share table with ranked bars matching policy shares, preserving source selection.
- Support expanded, icon-only and hidden sidebars. Reveal hidden navigation at the left edge and pin it back; retain the preference in the current management interface.

Includes client-list editing, persistent client statistics and the adjacent check/install update buttons from preceding betas.
