## 可信设备免登录 🏠

- “设置 → 安全”增加管理 IP 免认证白名单，支持 IPv4、IPv6 和 CIDR。匹配的设备可以直接访问管理页面、App 与 CLI，无需输入用户名密码。
- 白名单设备自动获得管理接口访问权限，无需在允许网段中重复填写。免认证按每次请求的客户端 IP 判定；移除白名单后，原匿名会话不能继续免认证。
- 设置按“管理认证与 TLS”“管理 IP 与反向代理”分组，提供字段说明；默认白名单为空，不改变已有登录要求。

## 反向代理与 CLI 🌐

- 可配置可信反向代理、外部 HTTP(S) 访问地址，并选择 X-Forwarded-For、X-Real-IP 或 Forwarded 作为客户端 IP 请求头。
- 多层代理从右向左确认客户端；忽略非可信来源的转发头，不在不同 IP 请求头之间回退。
- 支持代理域名与 HTTPS 终止，继续校验浏览器 Origin，并在外部 HTTPS 连接上使用 Secure 会话 Cookie。所有修改操作保留 CSRF 校验。
- CLI 支持通过反向代理域名访问，session 输出确认后的客户端 IP 和是否命中免认证白名单。
- 文档补充 Nginx 配置示例，以及直接访问和本机远程中继的 IP 判定差异。

### 测试提示

- 反向代理需明确配置可信来源，并覆盖所选客户端 IP 请求头及转发的 Host / Proto；域名访问需登记外部源地址。
- 非回环监听和可信代理仍需开启管理认证，非白名单设备使用账号密码登录。不要把代理来源 IP 用作免认证客户端。
- 本机 Controller 中继访问远端时，远端看到的是本机 Controller 的出口 IP。按浏览器 IP 匹配时，请直接访问远端代理。
- 实际反向代理部署尚未现场验证，欢迎重点反馈多层代理、IPv6 和代理 HTTPS 场景。
