# RoutePilot v1.0.4-beta.10

## 软件更新按钮

- 检查后出现的安装 / 升级按钮与「立即检查更新」并排，统一放在「保存设置」所在的底部操作行。
- 本机 App、浏览器及远程连接使用一致的布局，保留原有下载进度、升级确认和当前后端目标。

包含此前测试版的客户端列表行编辑，以及请求计数、分流统计、错误数和最后活动的跨重启持久化。

## Software update actions

- Place the install/upgrade button beside Check for updates in the bottom action row with Save settings.
- Use the same layout for the local App, browser and remote connections, preserving download progress, confirmation and the connected update target.

Includes client-list editing and persistent request, decision, error and last-activity statistics from the preceding beta.
