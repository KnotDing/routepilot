## 分流图标动起来

- 正常运行时，亮色轨迹沿分流图标线路从左侧进入，再流向两个出口。
- 图标不再缩放跳动，保持固定形状和宽度。动画表达应用正在工作，不代表实时流量大小。
- 服务异常、离线或需要登录时显示静态状态图标；系统开启“减少动态效果”时保持静止。

## 更新说明不再留白

- 原生更新窗口改为异步等待用户选择，避免同步模态循环阻塞 WebKit 与 Markdown 渲染。
- 离线 Markdown 文档完成首次渲染后再检查加载结果；缺少资源、加载失败或页面进程退出时显示明确提示。
- 保留可折叠的 Markdown 更新说明、与窗口一致的背景及三个并排的更新按钮。

## 管理窗口记住你的习惯

- 自动保存管理窗口的尺寸和位置，关闭后再次打开或重启 App 时恢复。
- 首次打开仍使用默认大小；macOS 根据当前显示器调整恢复的窗口位置。

## 分流模式与缓存页面整理

- “自动分流”“强制直连”“全部交给 Surge”集中在 **设置 → 路由 → 分流模式**，点击保存设置后对当前后端生效。
- 侧栏“总览”旁仅显示当前模式，移除通用设置中的重复入口。
- 决策缓存页面移除“乐观响应缓存已开启”说明及“待刷新响应”统计。响应缓存开关及说明保留在 **设置 → 缓存**。

## 安装

提供 Apple Silicon 的 DMG、ZIP、后台安装包和 SHA256SUMS。

原生更新窗口和窗口尺寸记忆需要更新 App；网页界面调整需要更新提供页面的后台，并刷新已打开的页面。
