# RoutePilot v1.0.4-beta.2

## 持久历史与按源监控

- 大屏监控新增「实时数据 / 历史数据」切换，支持最近一小时、六小时、一天、七天及自定义时间范围。
- 后台在页面关闭期间仍采集 DNS 统计，每五秒持久保存采样并合并为分钟历史，保留七天；正常重启后仍可查询此前的趋势、流向、策略命中和响应码分布。
- 新增按客户端源 IP 的流入数量、占比与响应数量。选择单个源后，流向图、策略 / 策略组和最终策略排行、响应码、历史与实时趋势均只显示该源，使用该源请求数计算占比。
- IPv4 与对应 IPv4 映射地址合并统计；无法识别的源、启用前未采集来源的旧累计数据和超出明细容量的数据分别标注，避免错归客户端。
- 服务中断、重启或采样缺口不绘制虚构连续速率；历史查询及保存错误会显示原因。旧版远端缺少历史或来源功能时局部降级，其余管理能力继续可用。

历史数据以统计采样时间归入分钟桶，最长查询七天。最多跟踪 512 个源和每源 64 种策略流向，超出明细单独合并并保留请求汇总；旧版本未采集的来源信息不补造。本页统计 DNS 请求处理路径和数量，不包含网络字节或后续上网流量。

## Persistent history and source monitoring

- Add **Live data / Historical data** views with one-hour, six-hour, one-day, seven-day and custom time ranges.
- Keep collecting DNS statistics while the page is closed, persist samples every five seconds, and aggregate them into minute history retained for seven days. Normal restarts preserve trends, flows, policy hits and response-code distributions.
- Show DNS ingress counts, shares and responses by client source IP. Selecting a source filters flows, policy / policy-group and final-policy rankings, response codes and both live and historical trends; percentages use that source's requests.
- Normalize IPv4-mapped addresses. Explicitly distinguish unidentified sources, old totals whose sources were not collected, and detail-capacity overflow.
- Leave service outages, restart boundaries and sampling gaps disconnected. Surface history query and persistence errors, and gracefully degrade unsupported history or source features on older remote backends.

History is assigned to minute buckets by observation time, with queries up to seven days. Up to 512 sources and 64 policy paths per source are tracked; additional details are grouped separately without losing request totals. Source information absent from older versions is not reconstructed. Statistics cover DNS request handling paths and counts, excluding network bytes and subsequent application traffic.
