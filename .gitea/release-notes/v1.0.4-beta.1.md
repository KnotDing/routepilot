# RoutePilot v1.0.4-beta.1

## 大屏监控

- 管理窗口新增「总览 → 大屏监控」，沿用现有界面风格，支持中英文、深浅主题、4K 大屏模式与小窗口。可点击按钮或按 Escape 退出大屏模式。
- 查看策略 / 策略组和最终策略的命中请求排行、数量及占比，展开明细可核对策略到实际 DNS 处理去向。
- 以流向图展示直接请求、透明拦截与本地记录、响应缓存、真实 DNS 上游、Surge DNS、拒绝 / 空响应的关系，流带宽度按请求数量同比例绘制。
- 显示 DNS 流入、上游处理请求、生成响应、处理中请求、平均耗时，以及最近六分钟的流入 / 响应速率、分流和响应码分布。
- 累计统计独立于查询记录，并在配置重新应用和正常重启后保留。未记录策略、超过明细容量及重启前未确认的请求单独展示；旧版远端缺少监控统计时给出升级提示。

本页统计 DNS 请求数量和处理路径，不包含网络字节或后续上网流量。速率趋势从打开监控页起采样；异常退出可能丢失最近尚未保存的统计。

## Monitoring

- Add **Overview → Monitoring** to the management window, matching the existing interface with Chinese/English, light/dark themes, 4K large-screen mode and responsive layouts. Exit with the button or Escape.
- Show request rankings and shares for policies / policy groups and final policies, with searchable details linking policies to actual DNS handling paths.
- Visualize addressed and intercepted requests flowing to local records, response cache, real DNS upstreams, Surge DNS and local refusal / empty responses. Ribbon widths use one scale based on request counts.
- Display ingress, upstream-handled requests, generated responses, in-flight requests and mean latency, plus six-minute ingress / response trends and decision / response-code distributions.
- Keep cumulative monitoring independent of query history and preserve it across configuration reapplication and normal restarts. Explicitly show unassigned policies, detail-capacity overflow and requests without persisted completion before restart. Older remote backends receive a focused upgrade notice.

These statistics describe DNS request counts and handling paths, excluding network bytes and subsequent application traffic. Rate sampling starts when the monitoring page opens; an abnormal exit can lose statistics not yet saved.
