## 乐观缓存可靠性统计 📊

- 决策缓存和响应缓存分别增加旧缓存命中、已核对、不一致、未核对请求数及不一致率，便于评估先返回旧值的可靠性。
- 按实际请求计数；一次刷新期间多个请求命中旧值会分别计入。刷新失败或未确认结果不会被当作一致，不一致率以已核对请求为分母。
- 决策比较分流结果与最终策略；响应比较 DNS 记录与响应结果，忽略请求 ID、TTL 倒计时、记录顺序和域名大小写等变化。
- 管理页面、状态 API 和 /metrics 均可查看。计数属于当前缓存实例，缓存实例重建或进程重启后重新统计。

## BGP 邻居详情 🔎

- 邻居列表每行末尾增加“详情”按钮，打开只读窗口查看会话与管理状态、双方 ASN、Router ID、连接配置和计时器。
- 展示消息收发计数、地址族前缀统计、双方通告能力，并可展开完整 GoBGP 运行快照；认证密钥已隐藏。
- 信息随页面自动刷新，本机与远程后端均支持。旧版后端仍显示已有状态和配置，并提示升级后查看完整详情。
- 发布统计反映本机 BGP 运行情况，不代表网关已安装路由。

这是测试版本。完整 App 安装包包含管理页面、后台与 CLI。
