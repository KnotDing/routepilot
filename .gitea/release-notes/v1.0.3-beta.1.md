## CLI 与 skill 设置跟随当前连接 🤖

- “设置 → CLI 与 skill”现在作用于当前连接的后端：连接本机配置本机，连接远程配置远端 Mac。App 管理窗口与普通浏览器行为一致。
- 页面显示目标地址、桌面用户及实际安装路径，CLI 开关、自动安装 skill 和 agent 多选项均从目标后端读取和保存。
- 安装由目标 Mac 的完整 App 助手执行，使用桌面用户目录；支持已有内容的覆盖 / 跳过、自动备份及禁用后的恢复。
- 设置持久保存在目标 Mac，运行中的 App 与后续启动共同使用，其他应用偏好保存不会覆盖这些设置。
- 旧版后端或 App 缺少该功能时，仅在此设置页提示更新；其余管理功能继续可用。

### 测试提示

- 本机和远端均需升级完整 App，才能通过远程连接配置 CLI 与 skill。
- 目标 Mac 的桌面用户需要已登录；优先使用 Surge 设置中指定的用户，未指定时使用当前桌面用户。
- CLI 登录仍使用独立的管理会话；启用 CLI 或安装 skill 不会自动保存管理密码。

这是测试版本，欢迎反馈本机、远程及浏览器中的设置体验。
